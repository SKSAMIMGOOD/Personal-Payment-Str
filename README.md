# 💳 UPI Payment Page

A modern, responsive UPI payment page built using HTML, CSS, and JavaScript. Users can scan a QR code or tap the **Pay Now** button to open their preferred UPI app and send money directly.

## ✨ Features

- 💎 Modern Glassmorphism UI
- 📱 Mobile Responsive
- 🚀 One-click UPI Payment
- 📋 Copy UPI ID
- 📷 QR Code Support
- 🎉 Toast Notifications
- ⏳ Loading Animation
- 🔒 No Backend Required
- ⚡ Fast & Lightweight

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)

## 📱 How It Works

1. Open the payment page.
2. Scan the QR code or tap **Pay Now**.
3. Your preferred UPI app opens automatically.
4. Complete the payment securely through your bank.

---

## 🔐 Privacy

This project **does not collect, store, or process any payment information**.

All payments are handled directly by the user's installed UPI application.
